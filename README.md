# Sovereign OS UI

The frontend interface for Sovereign Engine, built with React, Tauri, and Tailwind CSS.

## Features
- **Event-Driven IPC Bridge:** Non-blocking asynchronous integration with the Rust core.
- **Dynamic Junior Sub-Agent Panels:** Modular UI rendering for task-specific capabilities.
- **Decision Flow Visualization:** Real-time visibility into the agentic execution loop.

## Setup
```bash
npm install
npm run tauri dev
